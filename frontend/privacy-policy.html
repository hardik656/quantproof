Privacy Policy

Last updated: 13 November 2026

1. Who we are

QuantProof is a trading-strategy validation tool at https://quantproof.net. There are no user accounts. Paid access is a token stored in your browser. Questions about this policy: support@quantproof.net.

2. Information we collect

Files and broker data you send. When you validate a strategy, the file or the broker credentials you enter are uploaded to our API. The checks do not run only in your browser. That includes:

  • CSV trade history you upload
  • Alpaca API key and secret, used to pull account and order history for that request
  • An Interactive Brokers Flex token, query id, and account id, used to request a Flex statement for that request
  • Zerodha Kite tradebook or orders exports
  • TradingView alert payloads you send to a webhook session you created

What the server keeps.

  • The uploaded file itself is read in memory to run the checks. It is not written into the validation cache as a file.
  • The validation result (score, checks, equity curve, and similar figures) is cached in server memory, up to 50 recent runs, so a PDF or an AI plan can be generated for that run. That cache is not written to disk and is dropped when the process restarts.
  • TradingView webhook sessions (session id and the alerts received) are stored for 7 days so alerts can accumulate. Depending on how the server is configured, that store is either a JSON file on the server or a database table.
  • Paid access tokens, and Pro-token expiry times, are stored the same way so a purchase keeps working after a restart.
  • The IP address used for the free daily limit is kept in server memory until the limit resets or the process restarts. It is not written to the database by the rate limiter.

Email. If you submit an address on the site (the results-page signup, or the note when the free limit is reached), that address is sent to Formspree. We do not put it in our own database.

Payments. Card details are collected by Paddle (international orders; Paddle is the merchant of record) or Razorpay (rupee orders). QuantProof does not receive your card number. Paddle may share the buyer details needed to deliver the purchase, such as an email address and a transaction id. Razorpay processes the rupee order and its payment id.

Analytics. Google Analytics 4 (measurement id G-P8ZCZSKQSS) runs on these pages and sets first-party cookies such as _ga and _ga_P8ZCZSKQSS. The site is served through Cloudflare, which may set its own cookies to operate the network.

3. How the checks are run

The validation checks run on our API, hosted on Render (quantproof-backend.onrender.com). Your browser sends the file or the broker request there and displays the result.

A paid AI fix plan sends a summary of that result — check names, scores, and the written findings — to an AI provider. Providers are tried in this order when their keys are configured: Groq, Anthropic, then OpenAI. The raw uploaded file is not the prompt. If no provider is configured, the plan is not sent.

Broker credentials are used to fetch that run’s history. They are not saved as part of the validation result or the access-token store. You can revoke a broker key at the broker.

4. Who else receives data

We use these processors for the product as it works today:

  • Render hosts the API that runs the checks
  • Cloudflare sits in front of the website
  • Google Analytics measures page visits
  • Groq, Anthropic, and OpenAI may receive a validation summary when you request an AI fix plan
  • Formspree receives an email address you choose to submit
  • Paddle is the merchant of record for international checkout and handles that payment and its tax
  • Razorpay processes rupee checkout
  • Alpaca, Interactive Brokers, or Zerodha receive the request when you ask us to pull or you upload data from that broker

We do not sell trading data. We share it with a processor only to run the feature you used, or if the law requires it.

5. Your choices

There is no account to delete. You can:

  • Not upload a file, and not connect a broker
  • Revoke a broker API key at the broker
  • Clear this site’s local storage in your browser, which removes saved access tokens and the currency choice
  • Block or delete Google Analytics cookies in your browser. The validator still works if you do
  • Email support@quantproof.net to ask what we still hold (for example a paid token or a TradingView session) and to ask us to delete it. We aim to answer within 30 days

6. Cookies and browser storage

We do use cookies and browser storage.

  • Google Analytics sets _ga and _ga_P8ZCZSKQSS to distinguish visits
  • local storage remembers a currency choice on the pricing page, paid access tokens for 7 days, and whether you dismissed the cookie notice
  • session storage keeps a copy of an access token for the open tab

A short notice on each page says that analytics cookies are in use. Dismissing it stores that choice in local storage. It does not turn analytics off; use your browser if you want to block the cookies.

7. Requests about your data

Email support@quantproof.net to ask what personal data we still hold, or to ask us to correct, export, or delete it. We aim to respond within 30 days. Depending on where you live, that kind of request may be a right under the EU GDPR, the California CCPA, Singapore’s PDPA, or India’s DPDP Act.

QuantProof is an analytics tool, not a regulated financial service, and it does not provide investment advice.

8. Where data is processed

The providers named above process data in the countries where they operate. The API host, the AI providers, Paddle, Formspree, and Google are not limited to India. Razorpay is used for rupee payments. A file you upload can therefore be processed outside your country.

9. Children's privacy

QuantProof is not intended for children under 18. We do not knowingly collect personal information from children. If we become aware of such collection, we will delete it immediately.

10. Changes to this policy

We may update this policy by posting a new version on this page and changing the date above. There is no account email list to notify.
